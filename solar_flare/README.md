# GOES 8-19 X-Ray Sensor (XRS) AI-Ready Data Summary and Analysis Learning Journey

The GOES satellites have provided constant measurements of solar X-ray irradiance in geostationary orbit since 1976\. The uses, importance and features of this data set are explained in the text and code below. The Jupyter notebook in this learning journey demonstrates reading, analyzing, and plotting the GOES 8-19 XRS irradiance and data quality flags.
